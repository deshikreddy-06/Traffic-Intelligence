# GHMC traffic-data boundary

`ghmc_boundary.geojson` contains the GHMC_BND administrative polygon exposed by
Telangana Remote Sensing Applications Centre (TGRAC), in WGS84
longitude/latitude coordinates. It is retained for Hyderabad-specific traffic
data workflows; it does not limit route planning or GPS route origins.

Source layer: [TGRAC Hydra administrative layer, GHMC_BND (layer 4)](https://tgrac.telangana.gov.in/arcgis/rest/services/Hydra_Folder/Administrative_Layer/MapServer/4)

Retrieved 2026-11-03. Nationwide route inputs are restricted to an approximate
India geographic bounding box. The GHMC polygon is an administrative boundary,
not a claim about live traffic coverage.
